## 🎯 Project Purpose

English Learning AI Platform là một ứng dụng học tiếng Anh tương tác được thiết kế cho:
- **Học sinh** (Students): Học tiếng Anh với AI tutor, thực hành phát âm
- **Giáo viên** (Teachers): Quản lý lớp, giao bài tập, theo dõi tiến độ
- **Quản trị viên** (Admin): Quản lý toàn hệ thống, phân tích dữ liệu

---

## 💡 Core Features

### Student Features
- ✅ **Interactive Lessons**: Video lessons, AI conversations, vocabulary practice
- ✅ **Pronunciation Practice**: Real-time pronunciation checking with AI
- ✅ **Gamification**: Achievements, badges, leaderboards
- ✅ **Progress Tracking**: Detailed analytics, improvement tracking
- ✅ **Face Verification**: Biometric authentication using face recognition
- ✅ **Assessment & Tests**: Quiz, listening tests, speaking tests

### Teacher Features
- ✅ **Class Management**: Create and manage multiple classes
- ✅ **Content Assignment**: Assign lessons and materials to students
- ✅ **Progress Monitoring**: View student progress and analytics
- ✅ **Grading System**: Grade assignments and tests
- ✅ **Student Analytics**: Detailed performance reports

### Admin Features
- ✅ **Platform Management**: Manage users, classes, content
- ✅ **Analytics Dashboard**: System-wide analytics and reports
- ✅ **AI Usage Monitoring**: Track API usage and costs
- ✅ **Content Management**: Manage curriculum and lessons
- ✅ **User Management**: User lifecycle management
- ✅ **Notifications Management**: System notifications
